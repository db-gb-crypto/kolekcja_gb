# 🌐 GBR Blockchain Viewer (1999 Style)

> STRONA GŁÓWNA: https://db-gb-crypto.github.io/kolekcja_gb/


> 🔥 Retro web experience + Game Boy archive + Blockchain (BSV) 🔥  

Projekt to stylizowana na lata 90. strona internetowa, która działa jako **interfejs do przeglądania archiwum gier Game Boy zapisanych w blockchainie (BSV)**.

---

To nie jest zwykła baza danych.

To:
- archiwum kolekcji Game Boy
- zapis historii każdego kartridża
- integracja z blockchainem (Bitcoin SV)

Każda gra istnieje jako wpis:
- lokalnie (zdjęcia, opis)
- oraz w blockchainie jako trwały, niezmienny zapis
