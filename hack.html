ok chcesz hackowac roma?

najpierw: to NIE jest proste.
nie ma ładnych programow, tylko HEX i ból.

--------------------------------------------------------
[ CZEGO POTRZEBUJESZ ]
--------------------------------------------------------

- ROM NES (.nes)
- EDYTOR HEX (np. hex workshop)
- emulator (FCE Ultra albo cos)
- cierpliwosc (duzo)

--------------------------------------------------------
[ KROK 1: OTWORZ ROM ]
--------------------------------------------------------

wrzuc rom do edytora hex.

zobaczysz cos takiego:

4E 45 53 1A 02 01 00 00 ...

to jest header. NIE ruszaj tego.

--------------------------------------------------------
[ KROK 2: ZNAJDZ TEKST ]
--------------------------------------------------------

gry NIE trzymaja tekstu normalnie.

potrzebujesz pliku TABLE (.tbl)

przyklad:

41=A
42=B
43=C

zaladuj to do edytora.

teraz mozesz cos przeczytac.

--------------------------------------------------------
[ KROK 3: ZMIEN COS ]
--------------------------------------------------------

np. znajdz slowo:

"MARIO"

zmien na:

"JANUSZ"

zapisz rom.

odpal w emulatorze.

jak sie wywali: witaj w klubie.

--------------------------------------------------------
[ KROK 4: GRAFIKA ]
--------------------------------------------------------

grafika to kafelki (tiles).

uzyj edytora typu YY-CHR.

NIE:
- zmieniaj losowych bajtow
- nadpisuj wszystkiego

chyba ze lubisz glitch art.

--------------------------------------------------------
[ KROK 5: POINTERY (PIEKLO) ]
--------------------------------------------------------

tekst ma pointery.

zmienisz dlugosc = gra pada.

musisz:
- znalezc pointer table
- przeliczyc offsety
- wpisac nowe wartosci

jak nie wiesz co to:
jeszcze nie teraz.

--------------------------------------------------------
[ NOTATKI ]
--------------------------------------------------------

- rob backupy (SERIO)
- pracuj na kopiach
- wszystko sie wysypie (normalne)

--------------------------------------------------------

--------------------------------------------------------
